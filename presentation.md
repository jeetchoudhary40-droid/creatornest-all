# Creator Nest
## Pitch Deck & Architecture Overview

---

## 🛠 Tech Stack

**Frontend Framework:** Next.js 16 (App Router) with React 19
**Styling & UI:** Tailwind CSS v4, Framer Motion for micro-animations
**Icons:** Lucide React
**Design Aesthetics:** Cinematic Dark Theme, High Contrast Teal/Orange to ensure maximum accessibility and premium look-and-feel.

---

## 🏗 Architecture

- **Component-Driven UI:** Modular approach using `src/components/landing`
- **Roles-Based Gateways:** Smart routing for `/join` and `/tools`
- **Dynamic Assets:** Scalable particle effects overlay and performance-optimized rendering
- **Backend Readiness:** UI logic isolated to allow seamless FastAPI/Node integration

---

## 🔄 Demo Flow

1. **Discovery:** Eye-catching Hero section drawing you in.
2. **Intake:** Specialized Gateways allowing users to select "Brand" or "Creator".
3. **Value Prop:** Presenting the ecosystem showcasing Talent models & Toolkit utilities.
4. **Conversion:** Professional interactive intake forms.
